
# Trader Inventory Tracker

A simple sales and inventory tracker built for small traders in Nigeria who
currently manage stock and sales in a notebook or their head. This is my
first real software project, built while self-teaching software engineering
as a Banking and Finance undergraduate at Lagos State University.

🔗 **Live demo:** https://addisonp835-eng.github.io/trader-inventory-tracker/

## The problem

Many small traders track stock and daily sales manually, which makes it easy
to lose track of what's sold, what's left, and what's running low. This
project is a lightweight, no-login-required tool that lets a trader:

- Add products with quantity and price
- Record sales and automatically update stock levels
- See daily revenue at a glance
- Get a low-stock warning before they run out of an item
- View a running activity log of everything added or sold

## Built with

- HTML, CSS, and vanilla JavaScript — no frameworks, to keep it lightweight
  and dependency-free
- Fully responsive, works on both mobile and desktop

## Status

This is a work in progress. Data currently resets on page reload — the next
planned feature is persistent storage so a trader's data is saved between
sessions, followed by multi-day sales history and simple profit tracking.

## Why I built this

I'm not from a Computer Science background, but I saw a real gap: small
traders in my community lose money and time from disorganized record-keeping.
Rather than wait until I "knew enough," I started building — this repo is
proof of that, imperfect and in progress as it is.
